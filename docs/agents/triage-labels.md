# Triage 标签

这些 skill 使用五个标准 triage 角色进行沟通。本文件将这些角色映射到本仓库 issue 追踪器中实际使用的标签字符串。

| skill 中的标签 | 本追踪器中的标签 | 含义 |
| -------------------------- | -------------------- | ---------------------------------------- |
| `needs-triage`             | `needs-triage`       | 维护者需要评估该 issue |
| `needs-info`               | `needs-info`         | 等待报告人提供更多信息 |
| `ready-for-agent`          | `ready-for-agent`    | 已完全明确，可供 AFK agent 处理 |
| `ready-for-human`          | `ready-for-human`    | 需要人工实现 |
| `wontfix`                  | `wontfix`            | 不会处理 |

当 skill 提到某个角色（例如"应用 AFK-ready triage 标签"）时，使用本表中对应的标签字符串。

将右侧一列修改为你实际使用的词汇即可。
