# 视觉方向第五次改判：马卡龙 → 校样（press proof）

**背景**：本仓视觉方向由 `docs/adr/0014-visual-direction-modern-minimal.md` 定形态、`docs/adr/0015-macaron-palette-warm-cream-pastel.md` 再改判色板（马卡龙暖奶霜 + 五族 pastel），两者已全量落地并成为运行时真源。产品所有者在 `ui_redesign_impeccable` 分支上提出「redesign 整个 UI」，并在结构化访谈里明确：**日常四条路径（读流回消息 / 任务板认领与评审 / 找人找活 / 配置面）都必须先用得住**；首屏不点任何东西就要看出「谁在动、我漏读过什么、谁在等我裁决」；**视觉层全部可动，包括 token 名**；唯一硬失败信号是「**状态要猜**」——任何需要靠颜色或图标猜含义的状态都算失败。

**决策**：改用 **press proof（校样）** 世界。房间是一张校样：每个任务带着校次与签名，没有任何工作能在缺少第二个人署名时看起来「完成」。它拒绝的类别默认，是把工作状态藏在悬浮提示里的聊天气泡流。

世界只向应用借四样东西——**字、色、密度、一个签名动作**（ADR-0014 的 D2 与 `mode-operate` 的同一约束：世界不供给布局、导航模型与控件语汇）：

- **色**：校样白纸族（`--bg` 校样白 / `--surface` 卡面 / `--panel` 栏 / `--panel-2` 嵌套井）+ 单一墨族（`--fg` / `--muted` / `--faint`）。**四色只做角色，不做装饰**：青 `--selected*` = 当前所在，品红 `--unread*` = 等你审，黄 `--warn*` = 进行中，绿 `--online*` = 付印 / 完成，红 `--error*` = 退校 / 出错。`--accent` 是**墨族**：它的 base 就是实印面（主按钮 / 品牌 / 发送），纸白 `--on-accent` 压其上。
- **字**：系统 sans + 系统 mono，仍无 webfont；13px 界面正文、14px 消息正文 / 68ch、9.5px 全大写等宽标签、等宽 `tabular-nums`（ADR-0016 的阅读档位不动）。
- **密度**：三栏骨架、1080 / 900 断点、消息列居中、看板横向列全部保留；只是列宽从「固定 236」改为「236 为下限、320 为上限」——1920 屏上固定列会留下半屏空白。
- **签名动作**：**方形付印章**。`待审` 是品红虚线章、`完成` 是绿实线章并带署名、`已关闭` 灰、`进行中` 黄、`待认领` 墨。**章里永远写着状态词**，颜色不是唯一线索。成员行同样从「只有色块」改为「名字 + 状态词 + 方点」。

**为什么再改判（不是复述 ADR-0015 的论证）**：ADR-0015 的依据是「方向来源的层级」——提出要求的人是产品所有者本人，因此他的诉求高于任何资料。本轮同一个所有权重再次生效，且这次不是「换个配色」，而是所有者点名要**整屏重做**，并把判据从「观感」换成了可验证的产品条件：**状态不许猜**。马卡龙那套 fifth-pastel-per-role 的编码方式恰恰依赖「记住哪个浅色是哪个意思」，与这条判据正面冲突。

**为什么不是「改几个色值」（影响面是面，不是行数）**：

- **色板面**：`worksplice-design-system/colors_and_type.css` 整份换值并重写档位注释：纸族从暖奶霜改校样白、墨族从深梅改中性墨、`--accent` 从粉色 fill 改墨、五族 fill 全部降低彩度并提高 deep 档对比、头像 `--av-0…--av-4` 从「薰衣草 / 薄荷 / 蜜桃 / 柠檬 / 藕灰」改为五档**低彩度纸灰**（身份只靠首字母，四色留给角色）。`--soft` 配比从 22 / 21 / 36 / 24（四态 20%）改为 22 / 26 / 30 / 28（四态 28%），因为合成后的 ΔL 在原配比下达不到「看得见」的下限。
- **形态面**：圆角从 6 / 8 / 12 / 16 收到 **2 / 3 / 4 / 6**（`--r-pill` 也从 99 收到 3），presence 从圆点改**套准方点**，头像从 7px 圆角改**方砖 + 1px 内发丝**，`.badge` 从胶囊改近直角 + **墨底纸白**（未读不再借用角色色相），composer 焦点环从「3px 淡底雾」改「1px 实环」。
- **结构面**：新增「**四方色只做角色**」这条契约维度及其机械断言；`--accent` 一名三值同源（fill = deep = graphic = 墨）；`--stream-max` 880 → 1000、看板列宽改为区间。
- **文档面**：`worksplice-design-system/DESIGN.md` 重写为校样摘要并指向仓库根 `DESIGN.md`（构建后从代码写出，461 行、token 齐备）；仓库根新增 `DESIGN.md` 与 `PRODUCT.md`；`docs/spec.md` §4、`docs/css-variables.md`、`GLOSSARY.md` 的「档位」词条同步。
- **不动的面**：行为语义（消息不可变 / freshness-hold / 任务状态机 / inbox 游标 / 权限面 / agent-loop）、数据面（schema / `~/.worksplice` / HTTP 面）、三栏骨架与断点、13px / 14px / 68ch 的阅读档位、系统字体栈。**零行为改动**。

**迁移策略**：

- 色值仍改在 `colors_and_type.css`（上游即运行时真源），**不在 `app/globals.css` 覆盖同名 token**——`app/globals.test.mjs` T-A 的「同名 token 值逐字相同」仍要求这个形态；本仓扩展层只加 `--selected*` / `--unread*` / `--warn*` 三个产品角色族。
- **布局 / 间距 / 圆角 / 阴影的唯一声明处是 `tokens.css`**：本轮把 `colors_and_type.css` 里重复声明的那几段删掉了（import 顺序会让先声明的那份静默失效，本仓已经付过一次学费），并把 `--stream-max` 收成一处。
- **旧 token 名沿用 ADR-0014 / 0015 的同一条纪律：不留长期别名层。** 本轮没有改名（`--bg` / `--surface` / `--fg` / `--muted` / `--border` / `--accent` 等名字逐字保留），只是取值与档位语义变了。
- 机械断言同步改写：`app/globals.contrast.test.mjs` 按新色板重写（fill + 墨、deep + 纸白、deep 压四种纸、graphic 压 surface、头像五格、soft ΔL ≥ 3.0）；`components/{primitives,task-board,message-stream,dock}.test.mjs` 里编码旧形态的字符串级断言一并改为校样契约，并把「逐字搬自上游 app.css」的前提**降级为「class 块一个不少」+ 世界差异登记**（世界换了，形态来源不再是上游逐字）。
- **回滚可达**：改动集中在 `worksplice-design-system/{colors_and_type,tokens}.css`、`app/globals.css` 与少数组件标记，`git revert` 即回到马卡龙；无迁移步骤、无数据形态变化。

**被否决的备选**（含代价）：

- **（否决）只换配色、保留马卡龙形态**：所有者要的是整屏重做，且「粉 = 行动 / 薰衣草 = 当前位置」的语义编码正是「状态要猜」的成因之一；只换值会留下「2px 圆角配 99px 胶囊」这类自相矛盾的中间态。
- **（否决）恢复 brutalist**（0 圆角 / 2px 墨线 / 硬阴影 / 像素头像）：所有者的诉求里没有一个字要求回到那一套，且 ADR-0014 已论证它把「换色」膨胀成「换形态 + 换字体 + 换头像」。
- **（否决）保留马卡龙头像五色**：它们与四种角色墨共用色相，会把「这是谁」读成「这是什么状态」。改为低彩度纸灰后，身份只剩首字母——这是一致性优先于可区分度的**再次**知情取舍。
- **（否决）给消息行内加「付印 / 退校」按钮**：评审把这条列为 partial，但两个动词属于任务线程的可执行面，落在消息行会绕开「作者以外的人才能裁决」的既有边界。保持现状，等专用的状态权威票处理。
