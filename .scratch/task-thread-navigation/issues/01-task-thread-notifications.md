# 01 — 任务线程导航与未读（设计票）

Type: grilling
Status: resolved
Assignee: worksplice-dev (this session)
Blocked by: 无

## Question

围绕三项需求完成产品取舍并形成可实施设计：

1. 创建任务后的系统提示仅传达信息，不提供 hover / pop action、点击或再次转任务的 affordance；定义无障碍语义与视觉呈现。
2. 任务锚点消息快速区别于普通消息，并有明显入口直达对应任务 thread。
3. task thread 新消息在频道流的任务锚点上提示，所属 Channel 在侧栏提示未读；多任务线程时提供可扩展总览、排序/筛选、计数语义、打开与已读行为。

需要明确普通频道消息与 task thread 回复在各自消息序列、主频道未读、任务线程未读中的关系；覆盖切换频道、进入线程、同时多个线程未读、普通消息与线程回复交错。沿用现有 Channel / Task / thread 领域关系、现代简约 + 暖奶霜马卡龙视觉契约，不重开既有视觉裁决。
