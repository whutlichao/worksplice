## Question

raft.build 的 UI 细节：收集产品截图与界面元素，提取马卡龙配色 token（主色板、圆角、卡片、组件风格、明暗主题），形成一份可供 spec 直接引用的设计参考。

## Answer

详见 findings：[research/02-raft-visual-reference.md](../research/02-raft-visual-reference.md)

要点：官方色板 `--color-brutal-*`——奶油底 `#fffaef`、品牌黄 `#ffd440`（primary）、Bubble Pink `#fe7da8`（accent/CTA）、青 `#27ccf3`、橙 `#f8a16f`、柠檬绿 `#a9d877`、薰衣草紫 `#bbafe6`、珊瑚红 `#f97264`；ink `#141111` 文字 + 2px 黑粗边框 + 0 圆角 + 硬偏移阴影（brutalist 一面）；字体 Space Grotesk / Hanken Grotesk / Space Mono；仅亮色主题。产品内界面需登录，未能获取截图（已如实标注）。
