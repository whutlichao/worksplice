## Question

症状②：agent 继承了**其他 agent** 的会话/上下文。根因在会话文件解析的「所有权」边界。先确认哪条触发路径真实发生，再决策隔离规则并携带修复 + 单测。

**已钉死的结构事实：**
- `resolveLatestSessionFile(cwd)`：取 cwd 下最新、且**未被任何成员 `pi_session_file` 引用**的 session jsonl。`referencedSessionFiles()` 基于 `getDb().listMembers()`（`deleted=0` 过滤）→ **soft-deleted agent 的 session 文件不在引用集内**，成为可继承候选
- `startSession`：解析到的文件经 `setAgentSessionFile` **固化**为该成员的 `pi_session_file` → 借来的文件永久变成「自己的」，后续轮次与 backfill 全部基于它（粘性，与 04 联动）

**候选触发路径（逐一确认）：**
- (a) **deleted agent 文件失引用**：A 删除（soft-delete）后其文件不再被引用，新 agent B 绑到同一 cwd → `resolveLatestSessionFile` 把 A 的上下文解析给 B
- (b) **并发双启动解析到同一文件**：见 02-决策二，两 agent 同时拿到同一最新文件
- (c) **自身文件丢失后回退**：B 的 `pi_session_file` 指向的文件被删（reset/人工清理），`startSession` 回退 `resolveLatestSessionFile` → 解析到 A 遗留的最新文件
- (d) **人类 pi 会话不可排除**：人类在 pi-web 对该目录的会话永不进 `pi_session_file`，天然不在引用集——agent 是否可能继承人类会话（当前用户反馈以「继承其他 agent」为主，但确认一下）

**决策：会话文件所有权规则。**
- agent 只能解析/固化「属于自己的文件」。候选机制：`pi_session_file` 为唯一权威 + 首启即回填 + 解析结果做 cwd+文件归属校验（文件路径的 cwd 必须等于成员 workspace）；deleted agent 的文件永不继承；人类会话文件永不被 agent 解析
- 校验不过时的行为：让路不启动（记日志）还是新建空会话
- 既有已错绑的 `pi_session_file`（历史脏数据）是否清理、何时清理——与 04 联动

## Notes

- 与 02 联动：人类会话在同一 cwd 的「占用」判定语义（02-决策一）和「继承」判定语义（本 ticket）应一致

## Answer

### 触发路径确认

- 结构性确认：`referencedSessionFiles()` 基于 `listMembers()`（`deleted=0` 过滤）→ soft-deleted agent 的登记消失；人类 pi 会话从不登记；活 agent 的旧文件本就无登记。任何「无主文件」都可被 `resolveLatestSessionFile` 解析并被 `setAgentSessionFile` 固化——**借来的文件永久变成自己的**（粘性继承）。候选路径 (a)(c)(d) 全部坍缩为同一机制：**无主文件可被解析**。
- 修正 ticket 假设：`deleteAgentIdentity` 删除时物理删除当前 `pi_session_file`（失败窗口除外）——「deleted agent 的文件」实际残留形态：删除流程失败窗口、活 agent 的旧文件、换绑定目录后旧目录残留文件。
- 路径 (b)（并发双启动解析同文件）属 02 范畴；本 ticket 堵住其后果（同文件复用经归属校验自愈）。
- 用户未提供具体现场配置（Q1）——规则修法路径无关，不阻塞。

### 决策（所有权规则，ADR-0003）

1. **所有权凭证 = 固化登记**：`members.pi_session_file` 是会话文件归属唯一事实来源（jsonl 无归属元数据，SDK 格式只读，不可改）。
2. **复用校验**：`pi_session_file` 现值存在时必须通过归属校验——文件 cwd == 成员 workspace ∧ 不被其他成员固化引用 ∧ 在 session 清单内（listAll 可解析）。
3. **校验失败 = 历史脏数据 → 自愈**：清除错绑 + 新建空会话 + 记日志；不做批量清理（无法事后判定继承来源，文件可能仍有效）；无法事后判定的旧错绑由 04 保守跳过兜底。
4. **无主文件永不解析**：无绑定/文件丢失时仅家目录（构造唯一私有）回填 latest unreferenced；共享项目目录一律新建空会话。
5. **人类会话隐含排除**：人类文件从不登记 → 天然无主 → 永不解析（无需单独机制）；「占用判定」是独立一轴归 02，互不牵连。

### 修复（携带代码 + 单测）
