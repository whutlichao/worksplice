# 01: DM 通道地基与成员规则

**What to build:** 每个 agent 拥有一条 `type='dm'` 的一对一私信通道，成员创建时定死为 owner + 1 个 agent；DM 上禁止加人、退订、归档、离开、静音、改名；存量 agent 幂等补齐、新建 agent 同步建；agent 软删除后 DM 保留可读、不可写。

**Blocked by:** 无（可立即开始）

**Status:** ready-for-agent

- [ ] 频道类型支持 `dm`（CHECK 扩展 `('public','private','dm')`），schema 版本 +1，老库迁移兼容且可重跑
- [ ] 创建 DM 幂等：同一 agent 重复创建返回既有 DM，不产生第二条
- [ ] DM 成员恒为 owner + 1 agent，创建时定死
- [ ] join / leave / archive / mute / 改名 对 DM 一律拒绝（服务层抛错）
- [ ] 存量 agent 幂等补齐 DM；新建 agent 时同步建 DM（与自动加入 `#all` 同处）
- [ ] agent soft-delete 后其 DM 保留可读、不再可写
- [ ] 服务层测试覆盖上述全部行为
