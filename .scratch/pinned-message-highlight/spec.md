# Pinned 消息定位高亮

## Problem

从频道的 pinned 列表点击当前频道主消息流中的消息时，现有流程会滚动定位，但目标不够醒目。

## Solution

保留现有定位行为；定位到主消息流消息后，使用现有设计 token 给目标行短暂、清晰的高亮反馈，随后自动消退。重复点击同一条消息时重新开始高亮时长。thread pinned 项保持现有行为：只在右栏打开线程。

## Scope

仅覆盖 `ChannelView` 中 pinned 列表点击定位路径及消息行呈现。高亮不改变消息内容、排序、排列或既有固定样式；不修改深链、搜索等其他入口，不改数据层或持久化格式。
