# Pinned 消息定位高亮

## Problem

从频道的 pinned 列表点击当前频道主消息流中的消息时，现有流程会滚动定位，但目标不够醒目。

## Solution

保留现有定位行为；主消息流目标若尚未加载，使用现有 `loadEarlier/hasMore` 逐页加载至目标进入消息列表（目标比当前最新页更新时重拉最新页），再滚动定位并使用现有设计 token 给目标行短暂、清晰的高亮反馈，随后自动消退。重复点击同一条消息时重新开始高亮时长。分页中切换频道时，旧频道迟到的分页响应不得混入当前消息流。thread pinned 项保持现有行为：只在右栏打开线程。

## Scope

仅覆盖 `ChannelView` 中 pinned 列表点击定位路径及消息行呈现，并在 `useChannelData` 为该分页路径补充最小频道代际守卫。高亮不改变消息内容、排序、排列或既有固定样式；不修改深链、搜索等其他入口，不改数据层或持久化格式。
