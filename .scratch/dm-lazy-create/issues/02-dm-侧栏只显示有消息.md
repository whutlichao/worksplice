## 实施指路

1. **「有消息」信号**（`lib/domain/raft/channels.ts` `listChannelsWithMeta`）：给返回值附 `messageCount`（或
   `hasMessages`）字段。实现二选一，但与 01 迁移的「空」判定必须同源一致（顶层消息存在性）：
   - 复用 `maxSeq(channel.id) > 0`（消息 seq 单调自 1、不可变无删除，maxSeq>0 ⟺ 有顶层消息）；
   - 或新增 Store 读原语 `countMessages(targetId)`（`lib/data/store.ts` 契约 + `lib/data/sqlite.ts` 实现）。
   推荐前者（零 Store 契约扩展）。
2. **侧栏过滤**（`components/WorkspaceSidebar.tsx`）：`dmChannels` 的 `.filter((c) => c.type === "dm")` 之后
   再加 `.filter((c) => c.messageCount > 0)`（或 `hasMessages`）。普通频道分组不动。
3. **软删归档 DM**：软删 agent 的有消息 DM 由 `deleteAgent` 归档（`archived=1`），但 `messageCount>0` 仍为真 →
   照常渲染，`ChannelRow` 既有归档标记逻辑自然生效（可读）。无额外改动，测试锁定即可。
4. **测试 seam**：`components/WorkspaceSidebar.test.mjs` 渲染断言——构造有/无消息的 DM 行，断言空 DM 不出现、
   有消息 DM 出现、软删归档有消息 DM 出现且带归档标记；`lib/domain/raft/*.test.mjs` 断言
   `listChannelsWithMeta` 的 `messageCount`/`hasMessages` 正确。
