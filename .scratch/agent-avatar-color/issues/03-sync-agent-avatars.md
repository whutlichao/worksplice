# 03: 让全部协作界面的 agent 身份头像同步使用当前头像色

**What to build:** agent 头像色选择后，协作界面中代表该 agent 身份的所有现有 Avatar 都使用其当前身份色；已存在的历史消息也随当前身份色呈现，而非保留旧色快照。

**Blocked by:** 02 — 持久化 agent 头像色并提供详情页即时选择。

**Status:** ready-for-agent

- [ ] 侧栏、详情、频道与线程消息作者、任务 owner、成员选择、搜索命中作者及其他现有 agent 身份 Avatar 均呈现该 agent 当前的自动色或已保存色。
- [ ] 更改头像色后，上述呈现面同步反映新色；频道与线程中的历史消息及新消息都按作者当前身份色呈现，消息作者和消息内容保持不变。
- [ ] 人类头像始终使用 `av-4`；agent 头像只使用 `av-0…av-3`，且不同 agent 可呈现相同色格。
- [ ] 头像色只改变身份 Avatar tile；status dot、任务状态、作者名、主题及其他非 Avatar 语义色保持原样。
