worksplice design system · color 01

基础色板 · 表面、文字与强调色

产品的六个承重令牌 —— --bg / --surface / --fg / --muted / --border / --accent —— 以及它们的层级色。所有取值直接来自源文件 worksplice-app.html 的 :root，全部使用 oklch()，不得引入 hex。

索引 基础色 语义色 头像色 字体 间距 圆角阴影 按钮 状态 卡片 消息 品牌资产 应用界面

表面层级

bg → panel → surface
--bgoklch(99% 0.002 240)
--paneloklch(97.4% 0.004 250)
--panel-2oklch(95.6% 0.006 250)
--surfaceoklch(100% 0 0)

层级顺序用于制造纵深：页面底 → 侧栏/看板列 → 嵌套信息井 → 卡片/弹层。静止内容不加投影。

文字层级

fg / muted / faint
频道标题 · --fg oklch(21% 0.014 255)
次级正文与未激活标签 · --muted oklch(50% 0.014 255)
三级提示、占位符、时间戳 · --faint oklch(56% 0.013 255)
--fgoklch(21% 0.014 255)主文字 / 激活态
--mutedoklch(50% 0.014 255)次级文字
--faintoklch(56% 0.013 255)三级 / 元信息

强调色 · 单一品牌色

accent · 17° hue 256
--accentoklch(56% 0.17 256)
--accent-hoveroklch(50% 0.17 256)
--accent-softmix 11%
--accent-linemix 40%

全站只有一个强调色，语义是「Agent / 主操作」。每屏最多出现两次实心强调块（主按钮 + 状态点）。

描边与分隔

hairline only
--border · oklch(92% 0.006 250) —— 分隔线、静止卡片
--border-strong · oklch(85% 0.008 250) —— 输入框、可交互边框
虚线用于 .kv 键值行与字体样张的细分隔

令牌契约

don't rename

现有 Next.js 组件（AppShell、ChannelView、DetailPanel）按名字依赖这六个令牌。改色值可以，改名字会一次性击穿整个应用。

--bg页面画布
--surface卡片 / 面板 / 顶栏
--fg主文字 / 激活下划线
--muted次级文字 / 未激活
--border发丝分隔
--accent强调 / Agent
