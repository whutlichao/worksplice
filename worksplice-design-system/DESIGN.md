# worksplice — design system

> Category: Project Design System · Surface: web
> Direction: **Warm Action Surface（暖沙直觉动作面）**（暖沙外框 + 浮起暖白工作纸 + 深咖墨 + 单一朱砂行动色）
> Machine source: `colors_and_type.css`（色与字）、`tokens.css`（间距 / 圆角 / 阴影 / 布局）。
> 本文件是**人向摘要**；构建后的完整契约以仓库根 `DESIGN.md` 与 `.impeccable/design.json` 为准。

## 1. 方向

工作区是一张铺在暖沙桌面上的浮起暖白工作纸。90% 以上的视觉留在温和的暖沙、暖白、暖燕麦与深咖墨之间，把唯一的饱和朱砂陶土色留给「你可以立刻动手的地方」与「正在等你拍板的信号」。

## 2. 色法

- 纸面：`--bg` 暖沙画布 / `--surface` 浮起暖白工作纸与卡片 / `--panel` 看板列与页签底槽 / `--panel-2` 暖燕麦脉搏条与被动计数底。
- 墨与边：`--fg` 深咖墨 / `--muted` 暖褐 / `--faint` 暖灰褐，发丝 `--border` 做分隔、交互边 `--border-strong`（≥3:1）承接输入框与按钮。
- **单一饱和行动色 + 语义角色**：
  - 朱砂陶土 `--accent*` — 当前视口主 CTA（发送、批准、新建任务）与真实未读角标
  - 暖陶棕 `--selected*` — 当前位置（锚点消息、选中态）
  - 朱砂珊瑚 `--unread*` — 等你审（`in_review` 待审实心胶囊、审阅权限提示、命中高亮）
  - 暖蜜赭石 `--warn*` — 警示 / 防撞锁 / 提醒横幅
  - 森林鼠尾草绿 `--online*` — 在线 / 完成署名胶囊
  - 暖琥珀 `--working*` — 正在干活（脉冲圆点）/ 进行中
  - 深锈红 `--error*` — 出错 / 危险操作
  - 暖石灰 `--offline*` — 离线 / 已关闭
- 每一族严格按四档使用：`fill`（淡底压墨）· `soft`（淡提示底）· `deep`（文字 ≥4.5:1）· `graphic`（圆点与焦点环 ≥3:1）。
- 状态永远**同色同词**：脉搏条、任务胶囊、列头、成员行均直接写出状态词，颜色不是唯一线索。

## 3. 字

自托管可变字体 `Onest`（拉丁/数字）+ `JetBrains Mono`（序号/时间/状态词），无缝衔接中文字体栈（`PingFang SC` / `Hiragino Sans GB` / `Microsoft YaHei`），100% 离线提供自 `public/fonts/`。
`13px` 界面操作密度、`14px` / `68ch` 消息正文阅读预算、`9.5px` 全大写等宽分组标签，所有数字开启 `tabular-nums`。

## 4. 形态

暖沙软角体系：`6 / 10 / 14 / 18 / 999px`（`--r-sm…--r-pill`），1px 发丝边，暖咖着色三档轻阴影（`--shadow-composer` / `--shadow-card` / `--shadow-pop`）。
桌面端三栏带 `10px` 暖沙外框与 `18px` 圆角浮起工作纸；导航激活态为浮起暖白胶囊；状态点为 `7px` 正圆，任务状态与计数统一为真胶囊（被动计数用 `.badge.soft`）。

## 5. 反模式

- 不把饱和朱砂红浪费在被动计数（总回复数、成员数、无未读任务数）或普通正文/列表圆点上；左栏新建频道收敛为深咖墨 `--fg`。
- 不把 `fill` 当正文色、不拿 `soft` 当输入框边界；不加第二种饱和强调色、2px 以上粗边框或零模糊硬阴影。
- 不复活旧版 Press Proof 元素（2px 尖角、四色套准点、虚线方形付印章、左侧单边激活竖条）。
- 不让状态只有颜色没有词；不新增 emoji 当图标（仅用 `lucide-react`）。
